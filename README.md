# tarakany
Название программы: Игра «Тараканьи бега» (Windows Forms).  

<img width="406" height="245" alt="Unknown-11" src="https://github.com/user-attachments/assets/260453e4-fdb2-40f0-8a9e-9778cd34e0c9" />

Сброс: Чтобы начать игру заново, нажмите кнопку «Сброс». Все счетчики обнулятся, а тараканы вернутся на стартовую позицию.
 
Назначение: Программа представляет собой мини-игру для двух игроков, где побеждает тот таракан, который первым доберется до финиша.

Правила игры и порядок работы:

Ввод данных: В верхней части окна расположены два текстовых поля (textBox). Введите в левое поле имя первого игрока, а в правое — имя второго.
Начало игры: Нажмите кнопку «СТАРТ». Если имена не введены, программа выдаст сообщение об ошибке и попросит их заполнить.

Ход игры: После нажатия кнопки «СТАРТ» оба таракана начинают хаотично двигаться вправо. Скорость их перемещения зависит от генератора случайных чисел, поэтому победитель определяется случайным образом.

Над каждым текстовым полем отображается счетчик — пройденное расстояние (в условных пикселях). Тот, кто первым достигнет финишной черты (правого края беговой дорожки), объявляется победителем. Имя победителя выводится в центре экрана.
